# Related posts

Adds the `[related_posts]` shortcode: a list of published entries of the same type that share a category or tag
with the entry it appears on. Nothing is shown when there are none.

- **Attributes:** `count` (1–10, default 3) and `title` (default “Related posts”).
- **Permissions:** `content:read` — published content only, the same as visitors can see.
